Baseline definitions

These are the conceptual definitions supplied in the learning material. They are the baseline for the interactive examples.

Predictive AI

Infers a score, classification or forecast about a person or situation from historical data — for example, credit-risk, recidivism-risk or hiring-match scores.

Unique characteristic

It predicts or assesses something rather than creating content or independently executing a workflow.

Generative AI

Produces new content — text, images, audio, video or code — rather than a score about existing data.

Unique characteristic

It creates an output from learned patterns and an input such as a prompt or brief.

Agentic AI

Chains inference into multi-step action — planning, calling tools and executing transactions — rather than only outputting a prediction or piece of content.

Unique characteristic

It plans and acts across multiple steps toward a goal.

Foundation Model

A technical concept for a model trained on broad data at scale that can be adapted to a wide range of downstream tasks.

Unique characteristic

It is a reusable model layer, not a description of the end-user workflow.

GPAI

The EU legal category “general-purpose AI model,” covering models with significant generality and the capability to competently perform a wide range of distinct tasks and integrate into downstream systems.

Unique characteristic

A legal category for broad-purpose models in the EU.

LLM

A deep-learning model, typically transformer-based, trained on very large text corpora to predict and generate language across many tasks.

Unique characteristic

A language-focused model, commonly built with deep learning.

AI Agent

A software entity that perceives an environment directly or through tools, APIs and data, and takes actions toward a goal, often chaining model calls with planning, memory and tool use.

Unique characteristic

Perceive → plan → use tools → act.

Autonomous Agent

An agent capable of pursuing multi-step goals with reduced or no per-step human oversight.

Unique characteristic

It moves further along the autonomy spectrum.

Embodied AI

The technical idea that intelligence is instantiated in, and shaped by, a physical body that lets it perceive and act on the physical world directly.

Unique characteristic

Intelligence + physical body + perception/action.

Cyber-Physical System

An engineering category built from and dependent on seamless integration of computational and physical components.

Unique characteristic

Broader than robotics: it includes vehicles, smart grids, connected medical devices and IoT infrastructure.

Robot

An actuated mechanism programmable in two or more axes with a degree of autonomy, moving within its environment to perform intended tasks.

Unique characteristic

A physical machine that can move and act in its environment.

The central distinction

AI system describes the deployed machine-based system. ML describes a way the system can learn from data. Predictive, generative and agentic describe what the system does with inference. Deep learning describes a neural-network-based ML approach. These concepts can overlap.

Baseline wording is drawn from the supplied learning material; the OECD's updated AI-system definition similarly emphasizes inputs, outputs and varying autonomy. citeturn0search2turn0search7

📊 Machine Learning (ML)

Think: “the system learns patterns from data and improves task performance.”

📚➡️🧠➡️🎯

Definition

A subset of AI in which a system improves its performance on a task through statistical learning from data or experience, rather than through explicitly hand-coded rules for every case.

NIST describes machine learning as computer systems that adapt and learn from data with the goal of improving accuracy. citeturn0search1

Illustrative use case: dating match score

Inputs: profile attributes, stated preferences, interaction history, likes/skips and past match outcomes.

ML role: learn patterns associated with successful matches and produce a match score for a new pair.

Important: ML is the learning method. The surrounding app is the AI system.

Data path: historical interactions → features/patterns → trained model → match score → app recommendation.

🧬 Deep Learning

Think: “ML using multi-layer neural networks to learn complex representations.”

🧠🔗🧠🔗🧠

Definition

A sub-field of ML using multi-layered artificial neural networks to learn hierarchical representations from large volumes of data; it underlies much modern computer vision, speech recognition and large language models.

In the hierarchy from the supplied material: AI → ML → Deep Learning.

Illustrative use case: Reels video creation

Inputs: video frames, audio, captions, transcripts, engagement signals and editing examples.

DL role: learn representations for speech, visual content, scenes and language, which can support captioning, clipping, ranking or generation.

Output: components that the larger application can combine into a Reel.

Data path: multimodal training data → neural representations → model inference → clips/captions/audio choices → final application.

⚙️ AI System

Think: “the whole deployed machine-based system that performs the AI function.”

📥➡️🧠➡️⚙️➡️📤

Definition

The deployed artifact — hardware and software together — that performs an AI function in the world, distinct from “AI” as a field or an “AI model” as a trained artifact considered on its own.

The OECD definition describes an AI system as a machine-based system that infers from inputs how to generate predictions, content, recommendations or decisions that can influence physical or virtual environments, with varying levels of autonomy. citeturn0search2turn0search7

Illustrative use case: YouTube recommendation

Inputs: watch history, searches, clicks, skips, likes, subscriptions, video characteristics and contextual signals.

Models: ML/deep-learning components may estimate relevance or predict what a user is likely to engage with.

System: data pipelines + models + ranking logic + interface + feedback loop operate together to produce and update recommendations.

Data path: user/context data → models → ranked candidates → recommendation UI → new user behavior → feedback data.
